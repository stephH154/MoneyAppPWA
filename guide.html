02 記一筆

右下角（手機）或標題列（桌面）的「＋ 記一筆」開出表單：日期預設今天但可任選（跟你正在看哪一天無關）、支出／收入切換、分類、金額、備註。

－ 支出＋ 收入
分類 chip 列會依當下支出/收入自動過濾，只顯示同類型的分類

日期欄位是可點開的月曆選取器，不是打字輸入；分類 chip 列最後一顆「＋ 新增」可以在填表單填到一半直接加新分類，不用中斷。

03 滑除刪除

帳目列往右滑（或用滑鼠拖）過一定距離放開就會刪除，會先變成「已刪除「XXX」＋復原」，5 秒內按復原可以救回來，5 秒到了才真的刪掉。往左滑或滑不夠遠都會彈回原位，不會誤刪。

04 分類

每筆帳目要選一個分類，分類正式分「收入」「支出」兩種類型，記一筆表單只會顯示跟當下收/支一致的分類。

快速新增跟管理（改名／刪除／排序）是兩個分開的入口：記一筆表單分類 chip 列最後「＋新增」是低風險操作，怎麼方便怎麼來；改名／刪除牽涉既有帳目的顯示、收進設定頁「分類管理」，多一步才會動到。

05 固定收支

房租、薪水這類每月／每週／每天固定發生的收支，設定一次之後，到了日期會自動出現在當天帳本最上方「待確認」區塊，三個動作：確認（正式記一筆）、延後（明天再問一次）、這期跳過（這期不出現，下期正常）。過了原訂日期沒處理會標記「逾期」，不會自動消失，也不會自動幫你確認。

剛設定的固定收支不會倒填出一筆逾期——只會從設定當天開始往後算，不會因為「這個月稍早已經過了原訂日期」就一建立就跳出逾期。

設定頁「固定收支管理」列出所有定義（含已停用的），直接點一整列就會打開編輯表單——不需要先點編輯按鈕，因為表單裡本來就有「啟用」勾選框可以控制要不要繼續出現；🗑 刪除是獨立按鈕，會另外跳確認。

🖥️ 電腦

常駐側欄「📊 收支統計」按鈕，用浮框打開，跟固定收支管理／分類管理同一套機制。

07 雲端同步

設定頁「雲端同步」輸入一組專屬密鑰（密鑰要跟系統管理員索取，app 這邊不能自己生一組直接用）就能把資料同步到雲端，跨裝置共用同一份。

連結雲端同步按下去就是連結的動作：如果雲端還沒有資料，直接把本機現有資料當起點推上去；如果雲端已經有資料，會先跳出選擇（附本機/雲端各自的帳目筆數／固定收支筆數／分類個數，方便判斷）：

用本機覆蓋雲端
用雲端覆蓋本機
合併資料
取消

合併資料：帳目用 id 判斷同一筆，兩邊都有改過的話留比較晚更新的那筆；固定收支跟分類沒有修改時間可比，兩邊衝突時固定留本機這邊，只有其中一邊新增的項目會直接加進來。合併完會把結果推回雲端，兩邊會變成一致。

連結之後，之後每次改動都會自動同步，不用手動按「立即同步」（改動後幾秒內自動推送；「立即同步」按鈕還在，可以手動立刻觸發，按下去會轉圈圈提示正在處理）。如果兩台裝置各自都有新變更，會跳出跟連結時一樣的三選一（本機／雲端／合併）。

08 備份 / 清除資料

  • 匯出備份：下載一份完整 JSON（帳目、固定收支、分類都包含），當手動備份用。
  • 匯入備份：讀一個 JSON 檔案整包覆蓋現有資料，匯入前會跳確認。
  • 清除所有資料：把所有資料重置回空的狀態，無法復原。如果這台裝置目前有連結雲端同步，會先跳出三選一：「取消同步再清除」（雲端資料保留，只清本機）、「同步清除」（本機跟雲端都清空）、「取消」；沒有連結雲端同步的話就是單純的一次確認。

09 安裝成 App（PWA）

透過已經部署上線的網址開啟時（不是直接開本機這份 html 檔案），可以把小帳本「安裝」成一個獨立的 App 圖示，離線時也能開起外殼（資料本身在 localStorage，跟安不安裝無關）。

🖥️ 電腦

Chrome / Edge 網址列右側的「安裝」圖示，或瀏覽器選單裡找「安裝小帳本」。

📱 手機

Android（Chrome）：選單「⋮」→「新增至主畫面」。iPhone（Safari）：分享按鈕 →「加入主畫面」。

10 已知限制

·資料存在瀏覽器 localStorage，換瀏覽器或換裝置不會自動有資料，要靠雲端同步或手動匯出/匯入搬過去。
·雲端同步不是即時雙向同步，是「改動後自動推送 + 切回畫面時檢查」，兩邊真的同時改到才需要手動選一份（或合併）。
·「合併資料」只有帳目會比較修改時間，固定收支跟分類沒有時間戳可比，衝突時固定本機優先。
·總結分頁的分類顏色依名次分配，不是每個分類固定一色。
·CSV 匯入銀行對帳單、搜尋、備註側欄、提醒通知、鍵盤快捷鍵、交易列表拖曳排序——這幾項目前都還沒做。
·「安裝成 App」只有透過已部署上線的網址開啟時才有作用，直接開本機這份 html 檔案不會出現安裝選項，其他功能不受影響。
